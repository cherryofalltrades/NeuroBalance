# NeuroBalance wireframe

Static GitHub Pages site for the editable NeuroBalance mobile wireframe.

## Publish

1. Create a GitHub repository and upload the contents of this folder.
2. In **Settings → Pages**, set the source to **GitHub Actions**.
3. Push to the `main` branch. The included workflow publishes `index.html`.

The screen selector, navigation, and prototype interactions run in the browser. To edit the design, update `index.html` and push the change.
